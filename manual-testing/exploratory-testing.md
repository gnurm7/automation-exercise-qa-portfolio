# Exploratory charters

| Charter | Timebox | Investigation and evidence |
| --- | --- | --- |
| Cart quantity at the lower boundary | 25 min | EC-17. Start with a clean cart per value. Record field validity, submitted values, cart quantity and line total for blank, -1, 0, 1, 2 and 1.5. Compare keyboard entry with number-control arrows. Capture a short trace without identifiers. |
| Keyboard and narrow viewport | 25 min | EC-19. Follow products → detail → cart at 375px. Record focus order, visible focus, clipping and modal dismissal. Repeat at desktop width for comparison. |
| Session transitions | 25 min | EC-10/18. Compare logout, refresh, history, new tab and a separate browser profile. Note cart/authentication independently. Record whether a previously loaded page can make a fresh authenticated action. |

Check the published UI scenarios for the baseline. Record unresolved behavior as a product question using the [triage guide](../bug-reports/README.md).
